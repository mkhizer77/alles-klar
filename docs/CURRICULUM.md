# Alles Klar — Learning plan A1 → B1

A self-paced course that takes you from "I know some words" to a solid B1, with every grammar concept explained in plain English, searchable at any time, and practised with instant-feedback exercises.

## How the course is organised

- **Three levels** (A1, A2, B1) following the Goethe-Institut / CEFR "Kann-Beschreibungen" (can-do statements).
- Each level has **units**. Each unit has a handful of **topics** (one grammar or language concept each) and a **vocabulary theme**.
- Every topic page has the same shape so you always know what to expect:
  1. **What it is** – the concept in easy English, with the German term.
  2. **How it works** – rules, tables and examples.
  3. **How it connects** – links to the rules it depends on and the rules that build on it.
  4. **Watch out** – edge cases and common mistakes.
  5. **Practice** – 8–12 interactive exercises (multiple choice, fill-in, word order, matching, translate).
- Every concept also lives in the **Concepts** search, so "what is Dativ?" or "what is conjugation?" is one search away.
- Each level ends with a **level test** so you can judge where you stand.
- Vocabulary runs in parallel: a daily batch of new words plus spaced-repetition review.

## Suggested pace

| Level | Topics | Vocabulary | Time at ~25 min/day |
|-------|--------|------------|---------------------|
| A1    | 36     | ~550 words | 8–10 weeks |
| A2    | 32     | ~550 words | 10–12 weeks |
| B1    | 32     | ~600 words | 12–14 weeks |

A daily session: 10 min vocabulary (new + review), 15 min one topic or a practice set. Weekly: one re-read of a weak topic from the "Watch out" list.

If you already know some A1, use the **A1 level test** first; any area under 70 % is where to start.

## Skills beyond grammar (built in across units, speaking last)

- **Reading**: each unit from A1 U4 onward gets a short text with comprehension questions (added in the next build).
- **Writing**: guided writing tasks with model answers (A1 U8, A2 U10, B1 U10).
- **Listening**: sentences read by the device's text-to-speech (free on iOS/Android/desktop) with "type what you hear" exercises.
- **Speaking**: a conversation partner that uses on-device speech recognition and speech synthesis with an AI agent behind it. Built after the core course is in place.

## Adding content later (B2+)

Content is plain data files (one file per topic, one file per vocabulary theme). Adding a level is: add the level to the curriculum file, drop in topic files, and the app picks them up, including the level test.
